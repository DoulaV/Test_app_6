## model (what happens after you post) (t=t=01:45, t=02:50, t=03:30, t=04:50)

```
1. You post the video.
2. The algorithm maps the topic (computer vision, audio fingerprinting, metadata).
3. It tests it on about 200 viewers, mostly non-followers.
4. It analyzes performance and decides to boost (2,000, 20,000, 200,000), retry (another 200), or stop.
```

## principle (t=t=05:20)

```
Hack the algorithm in 2 steps:
1. Help the algorithm build a better fit score so it can find the best 200 person sample group initially.
2. Make sure that sample group actually engages strongly with your video.
```

## principle (audience matching) (t=t=06:45, t=08:35)

```
All you have to do is consistently make videos about the same topic for the same audience avatar over and over and over. To improve fit score, keep your topic and audience consistently narrow.
```

## warning (t=t=08:45)

```
Even one viral hit to an audience outside of your core demo will result in the next several videos having poor sample data because it confuses the algorithm.
```

## metrics (t=t=09:35, t=09:50, t=10:00)

```
1. Average watch time (seconds) and percent completion.
2. Engagement rate = (likes + comments + shares + saves + reposts) / views.
3. Watch time session share: the share of a viewer's session spent on your videos (not visible to creators).
```

## checklist (four engagement attributes) (t=t=10:50, t=11:05, t=11:15, t=11:30, t=11:50)

```
1. The topic is highly relevant to the ideal viewer: it solves a problem they have.
2. The information is non-obvious and tactically implementable.
3. The viewer has a high absorption rate: they understand what you say.
4. There is a short distance to implement: a small action gets the promised result.
In plain words: cover a core pain point; have something useful or interesting to say; say it in a way they can understand; make it something they can apply on their own.
```

## checklist (five comment tactics) (t=t=13:55, t=14:10, t=14:35, t=14:55, t=15:15)

```
1. Take a hard stance: pick a side.
2. Be contrarian: go against the majority when you actually disagree with it.
3. Amplify your take: stronger framing, stronger reactions.
4. Use polarizing topics: brands, people, or issues people already have opinions on.
5. Trigger emotion: make people feel something, not just think.
```

## example (amplification) (t=t=14:40)

```
Weak: This is the best way to cook pasta.
Amplified: This pasta is better than all the mom and pop pasta shops in the world.
```

## closing principle (t=t=16:10)

```
Posting time does not matter. Hashtags in your captions don't matter. The captions themselves don't matter. The only thing that matters is making great videos for a specific avatar group across a narrow band of topics over and over and over. That is the cake. Everything else is the icing.
```
