## schema (seven idea legos) (t=V2 t=01:24, V2 t=02:35)

```
1. Topic: the one-sentence description of what the video is about.
2. Angle: the premise, take, and key facts used to explain the topic.
3. Hook: spoken hook, text hook, visual hook.
4. Story structure: how the story is delivered (breakdown, listicle, tutorial).
5. Visual format: the visual layout (green screen, POV vlog, faceless text).
6. Key visuals: the A-roll, B-roll, animations actually shown.
7. Audio: background music or sound effects.
```

## formula (t=V2 t=03:13)

```
Outlier score = views of one video / average views of that channel. Example: 100,000 / 10,000 = 10x.
```

## checklist (five obsession elements, with failure and fix) (t=V1 t=18:50, V1 t=19:26, V1 t=20:10, V1 t=20:57, V1 t=21:24)

```
1. Be Relevant & Relatable (levels 1, 2, 3). Problem: topics too broad, chasing views. Fix: narrow your topic until it feels personal.
2. Small Effort, Big Reward (levels 2, 3). Problem: overcomplicating to seem valuable. Fix: simplify until anyone can act.
3. Be Non-Obvious (levels 1, 2). Problem: repeating the same ideas as everyone. Fix: combine ideas from outside your niche.
4. Show Proof (levels 1, 3). Problem: sharing ideas without evidence. Fix: get results first, then create content.
5. Make It Actionable (level 3). Problem: too much theory, no execution. Fix: break ideas into simple steps.
```

## checklist (belief shift, level 2) (t=V1 t=10:00, V1 t=10:55, V1 t=11:22)

```
1. Present information with a contrasting frame (before vs after, then vs now, A vs B).
2. Deliver the message through a relatable character who started where the viewer is.
3. Frame the path as a small cost for a large reward.
```

## checklist (action, level 3) (t=V1 t=15:12, V1 t=15:28, V1 t=15:56, V1 t=16:11)

```
1. Quantitative proof: specific, defendable numbers mapped to the result ("from 2 to 15,000 followers in 6 weeks", not "this will help you grow faster").
2. Tactically implementable steps broken to the atomic unit: show exact inputs that produced exact outputs. Never command.
```

```

Strong: show what one person looks like eating 100g, next to what they could look like eating 200g.
```
