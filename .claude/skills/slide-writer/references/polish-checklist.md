# Polish checklist

Run this on every deck before it leaves your hands. Look and feel is judged before
content is read, and senior readers notice (V20 t=00:30, V14 t=06:30). Items marked
[lint] are checked by `scripts/lint_pptx.py`.

## Storyline

- [ ] Reading only the titles gives the whole argument (V01 t=01:00)
- [ ] Every title is a full-sentence conclusion, not a topic label [lint, partly]
      (V01 t=03:00)
- [ ] Titles are specific, quantified where possible, at most two lines, free of
      absolutes [lint, partly] (V01 t=05:00 to t=07:30)
- [ ] Every number in a title still matches its chart after the latest analysis
      (V15 t=10:45)
- [ ] One message per slide; no-so-what slides are in the appendix (V01 t=04:30)
- [ ] The opening runs situation, complication, solution (V13)

## Page structure

- [ ] Every page is a table; no clotheslines (V06, V18)
- [ ] Parallel items share identical sub-structure (V10 t=07:30)
- [ ] Repeated sets keep the same order and icons everywhere (V02 t=22:00)
- [ ] Terms are introduced before they are used (V05 t=07:45)

## Layout

- [ ] 16:9 [lint] (V14 t=03:00)
- [ ] Nothing left of the title's left edge or right of the footnote's right edge
      [lint] (V02 t=08:45)
- [ ] Nothing runs into the footer area [lint] (V10 t=05:30)
- [ ] Title, body and footer in the same position on every page; no jitter [lint]
      (V05 t=03:45)
- [ ] Everything aligned to as few lines as possible, and evenly distributed
      (V14 t=06:30, V20)
- [ ] Text boxes have zero internal margins [lint] (V12, V20 t=06:30)
- [ ] Nothing off the slide; no hidden or invisible leftovers [lint, partly]
      (V15 t=11:45)

## Text

- [ ] One body font size; at most one deliberate hero-number exception [lint]
      (V05 t=02:45, V02 t=10:45)
- [ ] Bullets have a hanging indent [lint] (V10 t=05:30)
- [ ] De-worded: bullets, not sentences (V05 t=08:45)
- [ ] Selective bold on the words that carry each bullet (V15 t=10:00)
- [ ] The colour hierarchy runs darker for higher levels (V10 t=06:30)

## Charts

- [ ] The self-explanatory checklist in `charts.md` passes for every chart (V23)
- [ ] No 3D, gloss or surface charts [lint] (V04 t=12:00)
- [ ] No pie with more than five slices [lint] (V04 t=05:00)
- [ ] Gridlines and redundant axes removed [lint, gridlines] (V04 t=02:30)
- [ ] Colour only on the point being made (V04 t=01:30)
- [ ] ISO currency codes, consistent negatives [lint, currency] (V14 t=05:30)

## Objects

- [ ] No SmartArt [lint] (V08)
- [ ] No animations or transitions [lint] (V05 t=11:15, V15 t=11:45)
- [ ] Icons only beside their label, used sparingly (V11)
- [ ] No pasted chart screenshots (V05 t=07:30)
- [ ] Every image licensed for commercial use (V11 t=02:30)

## Sending

- [ ] Attach a PDF alongside the file for readers on a tablet (V15 t=12:45)
- [ ] Send single pages as their own file when only those are needed
      (V15 t=12:30)
