## Claude Code skills

Skills generated by `youtube-to-agent` from Kallaway's videos:

- `.claude/skills/hook-writer/`: opening hooks using the three-step formula (context lean, scroll stop interjection, contrarian snapback). Ask for a hook, an intro, or a fix for a weak opening.
- `.claude/skills/story-loop-writer/`: story and script bodies using the four-step addiction loop (stakes, big question, head fake, re-hook). Ask for a story to be more gripping, or for an audit of where people drop off.

- `.claude/skills/algorithm-strategist/`: what to make and for whom, using the sampling model (fingerprint, fit score, 200-viewer test, boost or stop), audience matching, the four engagement attributes, and comment stances. Ask why videos flop, which idea to make next, or how to niche down.

- `.claude/skills/brand-idea-miner/`: find validated ideas and shape them for an obsessed personal-brand audience, merged from two videos (idea mining: seven idea legos, outlier score, watchlists, hold and remix; power of suggestion: the five obsession elements and the bank shot). Ask for reel ideas, competitor research, a remix of a reference video, or an audit of an idea against the five elements.

- `.claude/skills/copy-sharpener/`: the words themselves. Research the audience in their own language, then make any copy clear, concise, concrete, conversational and rhythmic, score the hook, and close with one call to action. Ask for a rewrite of a bio, caption, landing page, email, ad, or the ending of a script.

The five work in sequence: algorithm-strategist fixes the avatar and topic band; brand-idea-miner mines and shapes the ideas; hook-writer writes the opening; story-loop-writer structures the body; copy-sharpener sharpens every line and writes the close.

Core skill:

- `.claude/skills/youtube-to-agent/`: turn any YouTube tutorial or shared video into a working Claude Code skill. Share a video URL or file and ask Claude to "turn this into a skill". Run `python3 .claude/skills/youtube-to-agent/scripts/setup.py` to see which of the three systems (the `/watch` plugin, a Gemini API key, the analysis framework) are ready.
